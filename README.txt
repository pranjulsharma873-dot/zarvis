ZARVIS Android Project

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Connect your Android phone with USB debugging enabled, OR use an emulator.
4. Run the app.
5. For APK: Build > Build App Bundle(s) / APK(s) > Build APK(s).

IMPORTANT:
This first APK packages the HTML/CSS/JS interface in a WebView.
The desktop Flask app.py is NOT automatically running inside the APK.
The original app.py and memory.json are included for the next native/offline AI integration step.
